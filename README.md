# ⚖️ BalanceNews AI (뉴트럴픽 / NeutralPick)
> **좌우 편향 기사들을 비교·분석하여 하나의 객관적이고 균형 잡힌 중립·중도 기사로 합성하는 AI 저널리즘 플랫폼**

---

## 📌 1. 프로젝트 개요 (Overview)

현대 미디어 환경은 동일한 사건이라도 언론사의 정치적·이념적 지향성에 따라 프레이밍, 강조하는 사실, 사용하는 감정적 어휘가 극명하게 갈립니다.
**BalanceNews AI**는 특정 진영에 치우치지 않고, 양극단의 보도에서 **공통 사실관계(Fact)**를 추출하고 **대립하는 찬반 논거를 5:5 대등한 비중으로 재구성**하여 시민에게 편견 없는 시각을 제공하는 인공지능 플랫폼입니다.

## 🔬 2. 핵심 알고리즘: 4단계 탈편향(De-biasing) 파이프라인

```
┌─────────────────┐       ┌─────────────────┐
│ 기사 A (진보 성향) │       │ 기사 B (보수 성향) │
└────────┬────────┘       └────────┬────────┘
         │                         │
         ▼                         ▼
  [ 1단계: 교집합 팩트 추출 (Fact Separation) ]
  • 객관적 사실(일시, 장소, 통계, 발표문)과 주관적 주장 분리
         │
         ▼
  [ 2단계: 프레이밍 & 쟁점 매트릭스 도출 (Frame Mapping) ]
  • 좌측 초점(형평성, 피해, 공공성) vs 우측 초점(효율성, 시장활성화, 국익)
         │
         ▼
  [ 3단계: 언어적 탈편향화 (Linguistic Neutralization) ]
  • 정서적/단정적 편향 어휘 제거 (예: '폭거/밀어붙이다' ➔ '추진하다')
         │
         ▼
  [ 4단계: 5:5 중립 구조 기사 합성 (Centrist Synthesis) ]
  • 로이터·BBC 저널리즘 준칙 적용 (중립 헤드라인, 사실관계, 양론 50:50, 향후 과제)
         │
         ▼
┌───────────────────────────────────────────────┐
│           최종 산출물: AI 중립 종합 기사          │
└───────────────────────────────────────────────┘
```

```bash

│   ├── crawler.js           # 외신(로이터, BBC, 구글뉴스) 실시간 RSS 크롤러 & 5:5 합성 엔진

└── src/
    └── analyzer.js          # 클라이언트 편향 어휘 필터 및 점수 분석 엔진
```

## 🚀 4. 실행 및 사용 방법 (How to Run)

### 방법 A. 웹 UI 즉시 체험 (무설치/오프라인)
1. `index.html` 파일을 브라우저로 엽니다 (`open index.html` 또는 파일 더블클릭).
2. 기본 내장된 4대 분야(`국내`, `해외`, `북한`, `이색 해외`) 총 16개 정통 신문 기사를 자유롭게 탐색할 수 있습니다.
3. 백엔드가 실행되어 있지 않아도 오프라인 모드로 안전하게 작동합니다.

### 방법 B. Node.js Express 백엔드 API 및 실시간 크롤링 연동
```bash
# 1. 백엔드 폴더로 이동
cd backend

# 2. 의존성 설치 및 서버 실행
npm install
npm start
# (또는 node server.js 로 즉시 실행)
```
- 서버가 실행되면 `http://localhost:4000`에서 REST API가 활성화됩니다.
- 브라우저의 웹 화면 상단에 **`🟢 백엔드 연동됨 (:4000)`** 뱃지가 표시됩니다.
- **`📡 실시간 크롤링`** 버튼을 누르면 구글뉴스, 로이터, BBC 등 실제 RSS 피드를 수집하여 5:5 중립 기사로 즉시 합성합니다.

## 📋 5. 중립 저널리즘 5대 편집 원칙 (Editorial Guidelines)

1. **엄격한 팩트-주장 분리 (Fact vs. Claim)**: 확인된 수치와 사실관계만을 도입부에 배치.
2. **동등한 발언권 (Equal Space)**: 찬성 및 반대 논거에 50:50 문단 분량 강제 할당.
3. **가치판단 어휘 배제 (Neutral Verbs)**: '선동', '폭거', '구국의 결단' 등 감정 유발 단어 차단.
4. **생략된 맥락 보완 (Context Completeness)**: 한쪽 진영이 의도적으로 누락한 팩트를 상호 보완.
5. **무색무취 헤드라인 (Objective Headline)**: 자극적 낚시성 제목을 배제하고 핵심 쟁점만을 명시.
